### ABE — schematic & PCB editor for your Eagle files

Eagle was retired in June 2026. **ABE** keeps your `.sch` / `.brd` / `.lbr` files working — opened directly,
saved byte for byte — and adds enclosure CAD, 3D, simulation and firmware tools in one program.
